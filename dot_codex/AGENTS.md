## Plans

When writing plan documents (including from plan mode), save them to `.docket/plans/` using the naming convention `YYYY-MM-DD-description-slug.md`.

## Messaging Codex sessions

When asked to message an existing Codex session, discover and use `codex_tui.read_thread` and `codex_tui.send_message_to_thread` with the supplied session ID. Check the thread's context before sending instructions.
